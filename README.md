# غراز | قهوة ومحمصة — Ghiraz Coffee & Roastery

موقع تعريفي عربي متجاوب، مبني بـ Next.js، دون قاعدة بيانات أو خدمات دفع. يستخدم الشعار المرفوع كما هو وصور غراز المتاحة.

## النشر على GitHub وVercel
1. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub (وليس ملف ZIP نفسه).
2. من Vercel اختر Add New → Project ثم Import لمستودع GitHub.
3. سيكتشف Vercel إطار Next.js تلقائياً؛ اترك إعدادات البناء الافتراضية واضغط Deploy.
4. بعد النشر، يمكن إضافة `NEXT_PUBLIC_SITE_URL` إلى Environment Variables بقيمة رابط الموقع النهائي، ثم إعادة النشر لتفعيل sitemap.
5. التحديثات التالية على الفرع المرتبط تؤدي إلى نشر تلقائي.

## إعداد روابط التواصل (مهم قبل إطلاق الطلب عبر واتساب)
افتح `lib/site.ts` وأدخل الرقم الرسمي في `whatsapp` **بصيغة دولية من دون +**، مثل `9665XXXXXXXX`، وأدخل روابط Instagram وTikTok وSnapchat وX وخرائط Google إذا كانت متوفرة. تُخفى الروابط غير المحددة تلقائياً، ويُحوّل طلب واتساب إلى صفحة التواصل إلى حين إدخال الرقم.

## ملاحظة على المنتجات
الصور الموجودة في `public/images` مصنفة إلى مشروبات وحلويات وأجواء وفق أسماء الملفات الأصلية. **لا توجد قائمة رسمية مؤكدة بأسماء المنتجات أو أسعارها**؛ لذلك يعرض الموقع كتالوجاً بصرياً بدلاً من اختلاق منتجات وأسعار. بعد توفر القائمة، يمكن ربط كل عنصر باسمه وسعره دون قاعدة بيانات.

## تشغيل محلي
```bash
npm install
npm run dev
```

## بنية الموقع
- `/` الرئيسية
- `/products` كتالوج الصور والفئات
- `/about` قصتنا
- `/gallery` معرض الصور
- `/contact` التواصل
- `/privacy` سياسة الخصوصية
- `/terms` الشروط والأحكام

الشعار: `public/ghiraz-logo.png` (الملف الأصلي دون تغيير). الصور محوّلة إلى WebP لتحسين الأداء مع الاحتفاظ بالملفات الأصلية لدى المستخدم.
